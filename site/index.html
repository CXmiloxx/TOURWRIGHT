Tourwright drives a real browser through your app, puts a guided focus on each element, speaks your narration and hands you an MP4 with captions and chapters. When the UI changes, you render again. No re-recording.

How it works

Three commands, from clicking around to a video that keeps itself current.

  1. 01

    Record or write

    Click through your app once and get a script, or write the YAML. Targets are roles and labels, not brittle CSS.

    $ tourwright record https://app.acme.com
  2. 02

    Render

    A real Chromium follows the steps; loads and waits are cut; the voice, captions, chapters and poster are made.

    $ tourwright render tour.yaml
  52 s · 12 captions · tour.mp4
  3. 03

    Check in CI

    After every deploy, each script runs in seconds. A renamed button fails the build with the step and the fix.

    $ tourwright check videos/*.yaml
  step 7: cannot find "Save" → "Save draft"

What you get

Everything a good product video does, done by the script.

Guided focus

Everything dims but the element; a ring, a bubble and a gentle zoom land on the exact word being said.

It edits itself

Page loads, slow jobs and voice synthesis are cut out. Narration never overlaps; music ducks under the voice.

Real apps, real logins

2FA codes, saved sessions, uploads, live events. Credentials never sit in the script, and never show on screen.

Private data, invented

mask swaps emails, phones and IDs for consistent fake ones: film production safely.

A cast of voices

Several voices per video, speed and pitch per line, exact pauses, a pronunciation dictionary, sound presets.

From laptop to cluster

One binary on a Raspberry Pi, or an API with a Redis queue, workers and S3. Linux, macOS and Windows.

Claude Code plugin

The MCP server plus a skill that writes the script, dry-runs it against your app, fixes the targets and renders.

# in Claude Code
/plugin marketplace add CXmiloxx/tourwright
/plugin install tourwright@tourwright

  http://localhost:3000 for new admins

Any other MCP client: npx -y tourwright mcp

GitHub Action

Render the tours on every release, or fail the build when a deploy broke one. The job summary shows the fix.

- uses: CXmiloxx/tourwright@v2
  with:
    scripts: videos/*.yaml
    command: check      # or render
  env:
    TOURWRIGHT_SECRET_APP_PASSWORD: ${{ secrets.APP_PASSWORD }}

Also: an HTTP API with a job queue and webhooks, Docker, Kubernetes.

# Code of Conduct

Tourwright adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to issues, pull requests, discussions and any other project space.

In short:

- Be respectful and welcoming, whatever someone's experience, background or language.
- Give and take criticism about the work, not the person.
- No harassment, insults, sexualized content or personal attacks.
- Do not publish other people's private information.
- Assume good faith; help newcomers find their way.

## Reporting

Report unacceptable behavior to the maintainers privately: open a private security advisory on GitHub
(the same channel described in [SECURITY.md](SECURITY.md)). Reports are reviewed promptly and kept
confidential. Maintainers may remove content, warn, or ban, as described in the Covenant's enforcement
guidelines.

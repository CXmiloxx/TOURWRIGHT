# Governance

Tourwright is a small project and keeps its process small.

- **Maintainers decide.** They review and merge pull requests, triage issues, cut releases and have the
  final word when there is disagreement. They are listed as the repository's maintainers on GitHub.
- **Lazy consensus.** A proposal in an issue or pull request moves forward if no maintainer objects within a
  reasonable time (about a week for larger changes). Silence means "go ahead"; objections come with reasons.
- **Bigger changes start as an issue.** New script syntax, breaking changes and new dependencies are
  discussed before code is written.
- **Roadmap.** It lives in GitHub issues labeled `roadmap`. Anyone can propose an item; maintainers apply the
  label.

## Becoming a maintainer

Contribute steadily for a while: reviewed pull requests, help in issues and discussions, good judgment about
scope. Any maintainer can propose you; you become one if no maintainer objects. Maintainers who step away
can return to contributor status at any time.
